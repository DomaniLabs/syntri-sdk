# syntri-sdk — Go

🔜 **Coming soon.**

The Go client for Syntri is planned. It will mirror the TypeScript SDK: a thin,
standard-library-only wrapper over `POST /v1/capture` exposing `Input`,
`Output`, and `Outcome`, returning an error rather than panicking on transport
failures.

```bash
go get github.com/domaniLabs/syntri-sdk/go  # not yet published
```

Want to help bring it forward? See [CONTRIBUTING.md](../CONTRIBUTING.md).

For an SDK you can use today, see [`../typescript`](../typescript).
